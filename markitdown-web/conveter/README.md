# Converter Web App

This directory contains the Flask application behind the older `markitdown-web` path.

## Quick Start

```bash
pip install -r requirements.txt
python app.py
```

Default local address:

- [http://localhost:5000](http://localhost:5000)

## Main Files

- `app.py` - Flask entry point
- `requirements.txt` - Python dependencies
- `templates/` - HTML templates
- `static/` - frontend assets

## Scope

This app is useful if you want a browser-based demo or lightweight internal web workflow.

If you want the main maintained user experience, use the Java CLI instead:

- [`../../java/README.md`](../../java/README.md)
